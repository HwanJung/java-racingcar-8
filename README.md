# java-racingcar-precourse

### 입력
- [x] 사용자에게 자동차 이름 문자열 받음
- [x] 사용자에게 시도할 횟수 문자열 받음

### 파싱
- [x] 자동차 이름 문자열을 쉽표를 기준으로 구분
  - [x] 구분한 문자열이 비어있다면 예외
  - [x] 자동차 이름 문자열 리스트를 반환
- [x] 시도할 횟수 문자열 정수로 변환
  - [x] 입력받은 문자열이 비어있다면 예외
  - [x] 입력이 숫자가 아니라면 예외
  - [x] 양수가 아니라면 예외
 
### 자동차
- [x] 이름 문자열을 파라미터로 받아 생성
  - [x] 이름이 5자를 초과한다면 예외
  - [x] 전진 거리에 대한 필드 초기화
- [x] 전진하는 의미인 move 메소드 생성

### 게임
- [ ] 라운드 진행
  - [ ] 자동차 마다 랜덤 숫자 돌려서 전진 결정
- [ ] 가장 많이 전진한 우승자 선정

### 출력
- [x] 시작 문구 출력
- [x] 각 라운드 결과 출력
- [x] 우승자 출력
